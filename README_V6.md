# CVSmart V6

## الجديد
- فرز السير الذاتية للموارد البشرية: حتى 10 سير دفعة واحدة، مسمى وظيفي + سنوات خبرة مطلوبة، ترتيب بنسبة ملاءمة وتصدير CSV.
- رفع السيرة بصيغ PDF وDOC وDOCX وصور JPG/PNG (وWEBP/BMP/TIFF) في السيرة الفردية وفي الموارد البشرية.
- 127 مسمى وظيفيًا في 22 قطاعًا (حكومي وخاص)، والمسمى يُحدَّد من محتوى السيرة نفسها.
- شهادات احترافية بحسب التخصص مع الموقع الرسمي والتكلفة التقريبية.
- تقرير تحليل بصيغة PDF بلغة بسيطة (من أيقونة «تقرير التحليل»، ثم «حفظ بصيغة PDF»).
- البرامج التدريبية: سدايا، طويق، سيسكو، دروب، مع روابطها الرسمية.
- الدورات (يمين) ومنصات التوظيف (يسار) منفصلتان، وكل أيقونة تفتح موقعها.
- في أسفل الصفحة: رابط المنصة بزر نسخ + باركود للجوال.
- النسخة السابقة محفوظة في مجلد previous_version.

## التشغيل المحلي (ويندوز)
RUN_CVSMART.bat ثم http://127.0.0.1:5000

## النشر على الإنترنت
**Render (مجاني، موصى به):** ارفع المجلد إلى GitHub ← Render ← New Web Service ← اختر المستودع ← يقرأ render.yaml وDockerfile تلقائيًا (ويثبّت OCR العربي).
**Replit:** ارفع الملفات كلها (مع مجلد backend) ← Run للتجربة ← Deploy للنشر. ملفا .replit وreplit.nix مرفقان.
**أي استضافة Docker:** `docker build -t cvsmart . && docker run -p 8000:8000 cvsmart`

بعد النشر افتح الرابط، ثم الصقه في خانة الرابط أسفل الصفحة ليتحدّث الباركود.

## إضافة منصة أو موقع
افتح app.js وأضف سطرًا في JOB_SITES (منصات التوظيف) أو COURSE_SITES (الدورات).

- التكاليف والروابط تقريبية وقد تتغير؛ راجع الموقع الرسمي.
